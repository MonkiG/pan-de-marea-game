# Instrucciones para Claude

Antes de analizar, modificar o documentar este proyecto, lee y cumple [`AGENTS.md`](AGENTS.md).

`AGENTS.md` es la fuente canónica de reglas del repositorio. En particular, exige registrar en [`PROMPTS.md`](PROMPTS.md) todos los prompts del usuario relacionados con el proyecto, agrupados por feature y asociados a sus archivos y commits reales.

No mantengas una copia alternativa de esas reglas en este archivo. Si cambian las normas de documentación, actualiza `AGENTS.md`.
